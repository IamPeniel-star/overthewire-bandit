# OverTheWire Bandit — Assignment 2

## Overview

This repository contains my work and documentation for the MENSEC Linux/cybersecurity practical assignment based on the OverTheWire Bandit wargame.

The exercise focused on developing practical Linux command-line and introductory cybersecurity skills through progressive challenges.

## Objectives

- Navigate and manage files from the Linux command line
- Understand Linux permissions and ownership
- Search for files using attributes such as name, size, owner, and group
- Work with text-processing commands and pipelines
- Decode and transform data using common command-line utilities
- Identify file formats with `file`
- Work with compressed files and archives
- Use SSH and SSH keys for remote authentication
- Understand standard input/output and error redirection
- Apply command-line problem-solving techniques to security challenges

## Progress

The Bandit challenges were completed sequentially through the required practical range (Levels 0–33).

For security reasons, passwords, private SSH keys, and other credentials are intentionally excluded from this repository.
